2.`return`关键字:
使用`return`关键字之后，方法就会直接结束并返回结果，所以说在这之后编写的任何代码，都是不可到达的
![[UCcAb9L8lfOzXMZ.png]]

如果我们的程序中出现了分支语句，那么必须保证每一个分支都有返回值才可以
![[WjUlRrPwA9EXThV.png]]
只要有任何一个分支缺少了`return`语句，都无法正常通过编译，总之就是必须考虑到所有的情况，任何情况下都必须要有返回值。

当然，如果方法没有返回值，我们也可以使用`return`语句，不需要跟上任何内容，只不过这种情况下使用，仅仅是为了快速结束方法的执行:

3.方法的创建与使用（c语言中叫函数）
**注意：** 方法定义时编写的参数，我们一般称为形式参数，而调用方法实际传入的参数，我们成为实际参数。

4.return的用法
return后的方法不会再执行:
![[Pasted image 20260605003249.png]]

因此，我们有一种快速结束的方法：
```java
void test(int a){
    if(a == 10) return;    //当a等于10时直接结束方法，后面无论有没有代码都不会执行了
    System.out.println("Hello World!");   //不是的情况就正常执行
}
```

6.值传递问题
```java
void swap(int a, int b){   //这个函数的目的很明显，就是为了交换a和b的值
    int tmp = a;
    a = b;
    b = a;
}
```
```java
public static void main(String[] args) {
    Person p = new Person();
    int a = 5, b = 9;   //外面也叫a和b
    p.swap(a, b);
    System.out.println("a = "+a+", b = "+b);   //最后的结果会变成什么样子呢？
}
```
输出a=5 , b=9，为什么没互换？
我们交换的仅仅是方法中的a和b，参数传递仅仅是值传递，我们是没有办法直接操作到外面的a和b的。

![[Pasted image 20260605011715.png]]

但在 Java 中，**对象是通过“引用”传递的**。你可以把 `person`理解为这个对象的一个“遥控器”。虽然方法里叫它 `person`，但它指向的依然是外面那个真实的 `Person`对象。所以，你在括号里放进一个对象，并在方法内部通过 `.`操作符去修改它的内部数据，外面的原对象也会被同步修改。

8.方法进阶使用

```java
void setName(String other) {
    name = other;    
}
```
或者是
```java
void setName(String name) {
    this.name = name;   //让当前对象的name变量值等于参数传入的值
}
```

```java
public static void main(String[] args) {
    Person p = new Person();
    p.setName("小明");
    System.out.println(p.name);
}
```


一个类中可以包含多个同名的方法，但是需要的形式参数不一样，方法的返回类型，可以相同，也可以不同，但是仅返回类型不同，是不允许的！
```java
int sum(int a, int b){
    return a + b;
}

double sum(double a, double b){    //为了支持小数加法，我们可以进行一次重载
    return a + b;
}
```

```java
public static void main(String[] args) {
    Person p = new Person();
  	//当方法出现多个重载的情况，在调用时会自动进行匹配，选择合适的方法进行调用
    System.out.println(p.sum(1.5, 2.2));
}
```

注意，如果仅仅是返回值的不同，是不支持重载的
![[N2TRuqEnxrKbpc8.png]]

方法之间是可以相互调用的：
```java
void test(){
    System.out.println("我是test");   //实际上这里也是调用另一个方法
}

void say(){
    test();   //在一个方法内调用另一个方法
}
```

因此刻印递归调用
```java
int test(int n){
    if(n == 0) return 0;
    return test(n - 1) + n;    //返回的结果是下一层返回的结果+当前这一层的n
}
```
