## 知识点

1.定义类
![[Pasted image 20260604163743.png]]

Person中写
```
public class Person {  
    String name;  
    int agr;  
}
```
Main中写
```
public class Main{  
    public static void main(String[] args) {  
        Person p1 = new Person();  //类分配对象p1
        Person p2 = new Person();  //类分配对象p2
        p1.name = “小明”;
        System.out.println(p1 == p2);  //输出false，比较的是指向的区域
        System.out.println(p1.name);
    }  
}
```

默认值：
```
public static void main(String[] args) {
    Person p = new Person();
    System.out.println("name = "+p.name);
    System.out.println("age = "+p.age);
    System.out.println("sex = "+p.sex);
}
```
![[zDRdFwhm6nebSJU.png]]
```
如果直接创建对象，那么对象的属性都会存在初始值，如果是基本类型，那么默认是统一为0（如果是boolean的话，默认值为false）如果是引用类型，那么默认是null。
```
