## 知识点

1.使用long时，必须在右侧加入L申明是long，否则编译器自动把long长度的数字转换为int导致编译错误。**（float 和 long都需要额外申明）**
```
public class Main{
	public static void main(String[] args){
		long a=123456789789789L;
		 System.out.println(a);
	}
}
```

2.隐式类型转换规则：byte→short(char)→int→long→float→double
```
public static void main(String[] args) {
    double a = 10.5, b = 66;   //整数类型常量也可以隐式转换到浮点类型
}
```

```
public static void main(String[] args) {
    float f = 9.9F;
    double a = f;    //隐式类型转换为double值
    System.out.println(a);
}
```
`由于double精度更大，所以说可以直接接收float类型的值`

3.想用char存储数字
```
public static void main(String[] args){ 
    char a ='5'; 
    System.out.println(a);
}
```

4.boolean只有`true`和`false`两种值
```
public static void main(String[] args) {
    boolean b = true;   //值只能是true或false
    System.out.println(b);  //输出true
}
```

5.`var` 关键字
在Java10之后，我们可以使用`var`关键字来根据后面的结果自动识别类型：
```
var a = 10;
```

6.整数和小数一起计算时，所有的整数都会变成小数参与运算，int会被转换成 double​ 类型
```
public static void main(String[] args) {
    double a = 8.0;
    int b = 5;
    System.out.println(a / b);  //输出1.6
}
```

7.强制类型转换
```
public static void main(String[] args) {
    int a = 10;
    short b = (short) a;   //在括号中填写上强制转换的类型，就可以强制转换到对应的类型
}
```

8.运算符的优先级
```
优先级 1 — 括号、数组下标、成员访问：() [] 
优先级 2 — 后缀自增/自减：a++ a-- 
优先级 3 — 前缀自增/自减、**正负号**、逻辑非、按位取反、强制转换：++a --a +a -a ! ~ 
优先级 4 — 乘、除、取模：* / %
优先级 5 — 加、减：+ - 
优先级 6 — 位移：<< >> >>> 
优先级 7 — 关系比较：< <= > >= instanceof
优先级 8 — 相等比较：== != 
优先级 9 — 按位与：& 
优先级 10 — 按位异或：^
优先级 11 — 按位或：|
优先级 12 — 逻辑与：&&
优先级 13 — 逻辑或：|| 
```
```
public static void main(String[] args) {
    int a = 8;
    int b = -a++ + ++a; 
  	//我们首先来看前面的a，因为正负号和自增是同一个优先级，结合性是从右往左，所以说先计算a++
  	//a++的结果还是8，然后是负号，得到-8
  	//接着是后面的a，因为此时a已经经过前面变成9了，所以说++a就是先自增，再得到10
  	//最后得到的结果为 -8 + 10 = 2
    System.out.println(b);
}
```

按位与 &（偏向0），只要有0那就是0
```
public static void main(String[] args) {
    int a = 9, b = 3;
    int c = a & b;    //进行按位与运算
    System.out.println(c);  //输出1
}
```

按位或 | （偏向于1），只要有1那就是1
```
public static void main(String[] args) {
    int a = 9, b = 3;
    int c = a | b;
    System.out.println(c);  //输出11
}
```

按位异或  ^ 两边不相同的情况下为1，否则为0
```
public static void main(String[] args) {
    int a = 9, b = 3;
    int c = a ^ b;
    System.out.println(c);  //输出10
}
```

位移运算符<<
```
public static void main(String[] args) {
    byte c = 1 << 2;    //向左移两位
    System.out.println(c);
}
```

关系运算符
```
public static void main(String[] args) {
    int a = 10, b = 20;
    boolean c = a > b;   //进行判断，如果a > b那么就会得到true，否则会得到false
}
```

&&     与运算，要求两边同时为true才能返回true
||     或运算，要求两边至少要有一个为true才能返回true
!      非运算，一般放在表达式最前面，表达式用括号扩起来，表示对表达式的结果进行反转
```
public static void main(String[] args) {
    int a = 10;
    boolean b = 100 >= a && a >= 60;   //我们可以使用与运算符连接两个判断表达式
}
```

短路
```
public static void main(String[] args) {
    int a = 10;
    boolean b = a++ > 10 && ++a == 12;
    System.out.println("a = "+a + ", b = "+b);  //右侧++a因为短路而直接跳过，因此a=11
}
```

三元运算符
```
public static void main(String[] args) {
    int a = 10;
    char b = a > 10 ? 'A' : 'B';   //三元运算符需要三个内容，第一个是判断语句，第二个是满足判断语句的值，第三个是不满足判断语句的值
    System.out.println(b);
}
```
```
当a > 10时，给b赋值'A'
当a <= 10时，给b赋值'B'
判断语句 ? 结果1 : 结果2

```

代码块：变量作用域
```
public static void main(String[] args) {
    int a = 10;   //此时变量在最外层定义
    {
        System.out.println(a);   //处于其作用域内部的代码块可以使用
    }
    System.out.println(a);   //这里肯定也可以使用
}
```

if-else if-else
```
public static void main(String[] args) {
    int score =  2;
    if(score >= 90)    //90分以上才是优秀
        System.out.println("优秀");
     else if (score >= 70)    //当上一级if判断失败时，会继续判断这一级
        System.out.println("良好");
     else if (score >= 60)
        System.out.println("及格");
     else    //当之前所有的if都判断失败时，才会进入到最后的else语句中
        System.out.println("不及格");
}
```

switch-case(case后还可以继续嵌套if，自行尝试)
```
switch (目标) {   //我们需要传入一个目标，比如变量，或是计算表达式等
  case 匹配值:    //如果目标的值等于我们这里给定的匹配值，那么就执行case后面的代码
    代码...
    break;    //代码执行结束后需要使用break来结束，否则会溜到下一个case继续执行代码
}
```
